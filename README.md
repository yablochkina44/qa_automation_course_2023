# Учебный проект: QA Automation Course 2023 

Это учебный проект, направленный на изучение автоматизации тестирования на Java. Новые классы и функционал добавляются по мере обучения.

## Структура проекта:
```
Проект
│
└───src
    └───test
        ├───java
        │   ├───examples
        │   │       ├───BestContributorToSelenide.java
        │   │       └───SelenideRepositorySearch.java
        │   ├───pages
        │   │       ├───CalendarComponent.java
        │   │       ├───RegistrationResultModal.java
        │   │       └───RegistrationPage.java
        │   └───tests
        │           └───StudentRegistrationFormTest.java
        └───resources
                └───test_picture.png
```

## Классы проекта: 

- `BestContributorToSelenide.java` и `SelenideRepositorySearch.java` в папке `examples` служат в качестве примеров тестов 
- В `pages` содержатся классы, связанные с объектами страниц: `CalendarComponent.java`, `RegistrationResultModal.java`, `RegistrationPage.java`
- В `tests` хранится файл тестов: `StudentRegistrationFormTest.java`
- В `resources` - test_picture.png, исходный материал для тестов
